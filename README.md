# Dhruv Upadhyay — Engineering Portfolio

An Awwwards-calibre portfolio engineered with **Next.js 14 (App Router)**, **GSAP 3**, **Lenis**, and **TypeScript**, paired with bespoke **Harmond Serif** and **Nohemi** typography.

Live Deployments:
- **Next.js Production:** [dhruvupadhyay-web](https://github.com/dhrux2/dhruvupadhyay-web)
- **Webflow Production:** [dhruvupadhyaydotcom.webflow.io](https://dhruvupadhyaydotcom.webflow.io/)

---

## Architecture & Technology Stack

| Layer | Implementation |
|---|---|
| **Framework** | Next.js 14 (App Router, Server Components & Client Runtimes) |
| **Animation Engine** | GSAP 3.12 + `@gsap/react` + ScrollTrigger |
| **Physics Scrolling** | Lenis 1.1 with bidirectional GSAP ticker synchronization |
| **Styling** | Tailwind CSS with Warm Parchment (`#E8E2D6`) & Obsidian (`#0E1219`) tokens |
| **Typography** | Harmond Serif (800 Italic / Expanded) & Nohemi (Display & Text weights) |
| **Interactive Canvas** | Fluid Signal Thread spline (`<svg>` cubic Bézier) & Magnetic Velocity Cursor |

## Flagship Products Featured

1. **Calumi** — Offline-first AI calorie & macro tracker engineered specifically for Indian cuisine (Expo SDK 57, React Native 0.86, SQLite, Supabase).
2. **Vaultsmith** — Client-side zero-knowledge cryptographic utility calculating exact mathematical entropy via inclusion-exclusion combinatorics ([vaultsmith.vercel.app](https://vaultsmith.vercel.app)).

## Local Development

```bash
# Clone the repository
git clone https://github.com/dhrux2/dhruvupadhyay-web.git
cd dhruvupadhyay-web

# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
